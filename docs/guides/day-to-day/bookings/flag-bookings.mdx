# Flag bookings that need attention

Flag a booking to mark that it needs a second look, so your team knows to check it before calling it done. Use it for anything that shouldn't slip through: a boat that came back with damage, a payment you still need to sort out, or a request you want to confirm.

## Flag a booking

Flagging works through booking notes. Add a note to the booking and flip the flag switch. That marks the booking as flagged and gives the note a red card so it stands out.

<InlineVideoPlayer videoSrc={flagBookingVideo} />

Flag a booking whenever something needs following up:

- A boat returned with damage to inspect or charge for
- A payment that's still open or needs checking
- A request or detail you want a colleague to confirm

You can flag a booking in any state, from draft to completed. The flag isn't a booking status, it sits alongside it. A booking can carry more than one flagging note if several things need attention. Anyone who can add booking notes can flag and unflag, so there's nothing extra to set up.

## Spot a flagged booking

Flagged bookings are easy to pick out:

- A flag pill in the header on the booking detail page
- A pill in the reference column on the [bookings overview](https://dashboard.letsbook.app/bookings)
- A red pennant on the booking bar in the [planning overview](https://dashboard.letsbook.app/planning)
- Red cards on the flagging notes themselves

Flag and unflag events also show up on the booking timeline, so you can see who flagged it and when.

## Clear a flag

Once the issue is sorted, open the booking, click the flag pill in the header, and clear it from the unflag panel.

The flag lives on the booking, not on the note. Archiving the flagging note won't unflag the booking, so always clear it from the pill when you're done.

## Find flagged bookings

On the [bookings overview](https://dashboard.letsbook.app/bookings), use the **Flagged** filter to show only bookings that need attention. See [search and filter bookings](/guides/day-to-day/bookings/search-and-filter-bookings#filtering-bookings) for the full list of filters.

## Flag automatically

Let the system do the flagging for cases you always want to check: cancelled bookings and late returns. Enable these rules in the [booking wrap-up settings](/guides/day-to-day/bookings/booking-wrap-up#auto-flag-the-ones-that-need-a-look).
