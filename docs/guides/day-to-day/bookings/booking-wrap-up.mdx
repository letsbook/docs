# Wrap up finished bookings

The Booking wrap-up page collects every finished booking that still needs something: a deposit to return, a balance to collect, an overpayment to refund. Work through them one by one or settle them in batch, and end the day with a clean slate.

<Button href="https://dashboard.letsbook.app/bookings/wrap-up">
    Open booking wrap-up →
</Button>

You'll also find a Booking wrap-up tile on your dashboard, with a badge showing how many bookings currently need action.

Every row shows the booking, what's still open, and the action it needs:

- Bookings with a clean deposit return get an inline Return button, settled on the spot
- Anything else shows its own verb (Handle deposit, Collect balance, Refund overpayment) and takes you straight into the [settle flow](/guides/day-to-day/bookings/return-deposits-and-refunds) on the booking
- [Flagged bookings](/guides/day-to-day/bookings/flag-bookings) carry their red pennant, so you check those before returning anything

Use the date toggle (All, 3+ days ago, or a custom range) to focus on the backlog, and the Awaiting payment tab for bookings where the money is on its way.

## Return deposits in batch

Select the bookings with a clean full return and return their deposits in one go. The returns run in the background, so you can move on while they process.

## Auto-flag the ones that need a look

Under [booking wrap-up settings](https://dashboard.letsbook.app/booking-wrap-up) you can enable two automation rules:

- **Flag cancelled bookings**: cancelled bookings get flagged automatically, so you decide about their money deliberately
- **Auto-flag late returns**: boats that came back late get flagged, handy when a late return means withholding part of the deposit

Both rules are off by default. Flagged bookings surface in the wrap-up list with a pennant, ready for a closer look.
